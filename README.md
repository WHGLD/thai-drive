# DLT Тренажёр — веб-приложение для телефона

Три раздела:
- **Тест** — 15 случайных вопросов из выбранных тем, на английском. Ответ проверяется сразу, есть пояснения из `fails/`.
- **Ошибки** — все ошибки из пройденных тестов (`questions/`) плюс новые из приложения. Показаны мой ответ и правильный. Вопрос уходит из списка после 2 верных ответов подряд. Можно запустить тест только из ошибок.
- **Знаки** — 182 знака в 4 категориях (из `signs/`), с поиском, описанием и пояснением.
- **Цифры** — три вкладки:
  - «Шпаргалка» — `numbers.md` в картинках: скорости столбиками, «лестница» расстояний, шкала сроков, цвета бордюров, штрафы. «Режим проверки» размывает ответы — нажмите на цифру, чтобы открыть.
  - «Расстояния» — игра «разложи по полкам»: карточку нужно отнести на полку с правильным расстоянием. Два набора: «Стоянка» (3 / 5 / 10 / 15 м) и «За рулём». Запоминается лучшее время.
  - «Скорость» — спидометр: для мотоцикла, мотоцикла ≥ 400 см³ и легковой в одной из 4 зон нужно поставить стрелку на лимит. В конце — таблица с ошибками.
- **Слова** — термины из `eng/glossary-en-ru.md`: таблица (поиск, разделы, «скрыть перевод») и карточки. На лицевой стороне — термин и вопрос из базы, где он встречается (слово подсвечено), или составленный пример; на обороте — перевод и ответ. «Знаю» убирает карточку из колоды, «Ещё учу» возвращает её в конец.

Прогресс хранится в браузере телефона (localStorage). Картинки грузятся с safedrivedlt.com и testdrivinglicence.com, поэтому при первом просмотре нужен интернет. Дальше приложение работает офлайн, а просмотренные картинки берутся из кэша.

## Как открыть на телефоне

Приложению нужен адрес **https**: без него не работает офлайн-режим и установка на экран.

### Вариант 1 — Netlify Drop (проще всего, 1 минута)
1. Откройте https://app.netlify.com/drop на компьютере.
2. Перетащите туда папку `web-app` целиком.
3. Получите ссылку вида `https://….netlify.app` и откройте её на телефоне.
4. Добавьте на главный экран: в Safari «Поделиться → На экран Домой», в Chrome «⋮ → Добавить на главный экран».

Чтобы обновить сайт после новых тестов, пересоберите данные (см. ниже) и снова перетащите папку в тот же сайт: Deploys → «Drag and drop».

### Вариант 2 — GitHub Pages
1. Создайте репозиторий и положите в него содержимое папки `web-app` (без `_build` можно).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет по адресу `https://<логин>.github.io/<репозиторий>/`.

На бесплатном аккаунте репозиторий для Pages должен быть публичным. Личных данных в приложении нет: только вопросы, ответы и знаки.

### Быстро проверить на компьютере
```bash
cd web-app && python3 -m http.server 8000
```
Затем откройте http://localhost:8000. По Wi-Fi с телефона (`http://<IP-компьютера>:8000`) тоже откроется, но без офлайн-режима.

## Обновить данные после новых тестов
После того как в `questions/`, `fails/`, `signs/` или `eng/glossary-en-ru.md` появилось новое, выполните из папки `thai-drive`:
```bash
python3 web-app/_build/build.py
```
Скрипт пересоберёт `web-app/data/data.js` и обновит версию кэша, чтобы телефон подтянул новую версию. Потом выложите папку `web-app` заново.

## Офлайн и картинки
Все 357 картинок лежат в `img/` (`img/q` — картинки вопросов, `img/signs` — знаки; в `manifest.json` записано, откуда каждая скачана). При первом открытии с интернетом приложение сохраняет на телефон себя, данные и сразу все картинки (~5 МБ). Внизу экрана «Тест» видно состояние: «✓ Работает без интернета · сохранено 357 картинок». Если там «сохранено N из 357» — нажмите «Докачать».
Если в базе появятся новые вопросы с картинками, сборщик предупредит «картинок без локальной копии» — такие картинки грузятся из интернета, пока их не скачать в `img/`.

## Файлы
| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `app.js` | приложение |
| `data/data.js` | вопросы, ошибки, пояснения, знаки (генерируется) |
| `data/numbers.js` | данные раздела «Цифры» — переносятся из `numbers.md` вручную; если меняете `numbers.md`, поправьте и этот файл. Карточки игры «Расстояния» — в `sort` |
| `sw.js`, `manifest.webmanifest`, `icons/` | офлайн-режим и установка на экран |
| `img/`, `data/images.json` | картинки и их список для офлайн-кэша |
| `_build/build.py` | сборщик данных из md-файлов |
| `../eng/_src/examples.json` | примеры для карточек слов, которых нет в базе вопросов (остальные ищутся автоматически) |
